Standard Operating Procedures

This guide covers everything volunteers need to know about taking, tracking, fulfilling, and managing ice orders during the NC Azalea Festival.

Quick Reference: Each bag is $10 · Festival Office orders are excluded from revenue · Always mark orders as Delivered once dropped off

1. Taking an Order

  • Answer the phone or greet the vendor at the booth.
  • Ask for: Phone number, Contact name, and Vendor/booth name.
  • Ask how many bags of ice they need (each bag is $10).
  • Ask for delivery location / booth number if possible.
  • Confirm whether this is a Festival Office order (these are excluded from revenue).
  • For non-Festival Office orders, ask if they're paying now (cash) or on credit.
  • Enter your name as the volunteer who took the order.
  • Add any special notes (e.g., "needs by noon", "fragile setup area").
  • Review the total with the caller, then tap Submit Order.

2. Fulfilling an Order

  • Go to the Dashboard and find the order in the Pending list.
  • Mark the order as Out for Delivery before leaving with the ice.
  • Load the correct number of bags onto the cart.
  • Deliver to the correct booth or location listed on the order.
  • Collect cash payment if the order is marked as "Pay Now."
  • Return and mark the order as Delivered immediately after drop-off.
Important: Always mark orders as Delivered once dropped off — this keeps the dashboard accurate for all volunteers.

3. Handling Payments

Order Type Payment Counts Toward Revenue?
Regular Vendor Cash or Credit Yes
Festival Office Internal / No charge No
Payment Rules
  • Each bag of ice costs $10. Total = bags × $10.
  • Credit orders are paid later — note this in the system when submitting.
  • Place all collected cash in the designated cash box at the booth.

4. Using the Dashboard

  • The Dashboard shows all orders grouped by status: Pending, Out for Delivery, Delivered.
  • Use filters to find orders quickly by name, booth, or payment type.
  • Tap any order card to view details or update its status.
  • Revenue totals at the top reflect delivered, non-Festival-Office orders only.
  • If you need to edit an order, tap Edit and save changes before leaving the screen.
Tip: Refresh the Dashboard periodically so you see orders taken by other volunteers at the booth.

5. Common Issues & Tips

  • Wrong bag count delivered? Edit the order on the Dashboard to reflect the actual quantity and note the discrepancy.
  • Customer can't be found? Call the number on the order. If unreachable, return the ice and mark the order as Pending with a note.
  • Running low on ice? Alert the booth lead immediately so a resupply can be arranged.
  • App not loading? Refresh the page. If the issue persists, use the paper order sheet as backup and enter orders once the app is back online.
